Browser Window

Navigation Toolbar

The Navigation Toolbar in the browser window contains several buttons and the address field so you can enter web addresses and search terms.

The Navigation Toolbar can be customized by selecting the menu item View > Customize Toolbar and you can switch it on/off using the menu item View > Show Toolbar.

Favorites Toolbar

The Favorites Toolbar is displayed below the Navigation toolbar and shows the bookmarks which are located in the "Favorites" folder of the bookmarks collection.

Clicking the buttons of the Favorites toolbar will open the web page in the current Tab or window. Holding down the keys Cmd and/or Shift while clicking the favorites will open them in new windows or tabs, in the foreground or background, depending of the settings in the "Window" settings of iCab.

The menu item View > Favorites Toolbar can be used to switch on/off the favorites toolbar.

Sidebar

At the left side of the browser window it is possible to have a sidebar, which gives fast an easy access to the Link Overview, the Page Overview and to the Tab Groups. To enable or hide the side bar, you can use the menu item View > Sidebar or the sidebar icon from the navigation toolbar (customize the toolbar to add the icon if it is missing here).

Tabs

You can open multiple web sites in a single window at once, in which case these sites will be organized as Tabs. You can add new Tabs using the + button in the Tabs toolbar, but also by selecting the menu item File > New Tab. The menu item File > New private Tab open a "private" Tab, which does not save any private data (Cookies, History, Cache etc) permanently in the browser. You can recognize private Tabs by the red border around the address field.

The menu item View > Show all Tabs shows all Tabs with a preview image in a grid. You can reorder Tabs via Drag & Drop, and even convert a Tab into a window by dragging a tab out of a window.

Main Content

The main areas of the window shows the web site that is currently loaded. You navigate between web sites by clicking links and buttons.

Using the contextual menu (hold down the Control key while clicking, or click with the right mouse button) of a link or photo, you get the option to open the link or photo in a new window or Tab or download the linked files. While the contextual menu is open, you can also hold down the Shift and/or Option key to get some additional options, for example to open Tabs or windows in the foreground or background.

You can also directly click on links while holding down the keys Shift and/or Option to open the link in a new Tabs or window in the foreground or background directly.

Which keys have which effect can be configured in the window settings of the preferences dialog.

Clicking on a link with the Option- key pressed will directly download the linked file.

Status bar

The status bar at the bottom of the browser window is used to display status information like the destination of a link on wich you point with the mouse cursor. You can also add modules to the status bar so you can access them fast and easy.

The status bar can be switched on/off with the menu item View > Show Status bar.
