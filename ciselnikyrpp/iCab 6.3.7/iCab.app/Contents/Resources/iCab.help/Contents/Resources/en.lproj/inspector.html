Inspector

The menu item Tools > Web Inspector opens a window were you can inspect and debug the current web site on code level. This is a feature which is interesting especially for web developers to analyze the structure of their web page. This feature requires at least macOS 10.14 (Mojave)

The menu item Tools > Web Resources directly opens the "Resources" page of the web inspector.

The menu item Tools > Web Console directly opens the "Console" of the web inspector.
