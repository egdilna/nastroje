Links Overview

The menu item Tools > Links Overview opens a new window which lists all links of the current web site. Clicking these links will open them in the browser window. This feature can be very useful on "news pages" which provide a large number of links to articles. Because the links remain visible all the time in the Links Overview window, it's very easy and fast to read all the articles.

The top of the Links Overview has a check box Auto-update, which when checked will automatically update its links list to the links of the currently active window or Tab. When unchecked, the Links Overview keeps all the links when switching Tabs or navigating to new web sites, unless you manually click the Update button. This is useful when reading multiple articles of a site one after another, because then the links remain visible and you can click on them one after another to read the web site.
