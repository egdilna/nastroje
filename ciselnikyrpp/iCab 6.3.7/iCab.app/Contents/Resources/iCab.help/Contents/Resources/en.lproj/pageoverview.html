Page Overview

The menu item Tools > Page Overview opens a small floating window which shows all of the headings of the currently displayed web page. This is useful to get an overview of web pages with longer texts. Clicking these headings in the Page Overview window will immediately scroll to this heading in the web page. So the page overview will also help to navigate within larger web pages.

When switching to another Tab or Window or when opening a new web page, the Page Overview window will automatically update itself.
