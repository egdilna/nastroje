Phishing/Malware Detection

You can enable the Phishing/Malware detection in the Security panel of the Settings. This feature uses the Phishing/Malware detection feature that is provided by Google. Whenever iCab is about to open a web page it will check if this page can be found in the database of known malware and phishing sites. If this is the case, iCab won't open the page and displays a warning to the user. The user still has the ability to open the page nevertheless by responding to the warning accordingly.

All checks are done within iCab itself, so Google won't get any information about the web sites you visit. iCab only has to update the database with the known malware/phishing sites regularly (this is done using "hash values")
