Reading List

Reading List

The Reading List allows to save web pages which you want to read later. This is similar to saving bookmarks, though the main purpose is not to save these pages permanently but instead only until the user has read them. The Reading List therefore consists of three views: the unread pages, the read pages and all pages. The list of read pages will only save a certain number of pages, so the older pages which were already read will be removed automatically.

The Reading List can be opened using the menu item Tools > Reading List. The + button can be used to add the current web site to the reading list, which is also possible using the menu item View > Add to Reading List.

Clicking an entry within the reading list will open the web page in the browser and moves it into the list of "read" items.

Reading Mode

If you click on the "glasses" icon in the reading list, the web site will open in a special Reading Mode. This special mode will remove everything from the web site that does not belong to the main content (like ads, navigation menus, etc), so the text is much easier to read.

The Reading Mode can be also enabled independently of the Reading List using the menu item View > Reading Mode .

Important: The Reading Mode only works on web sites which only contain a single text or article. In case iCab can not detect a single article, it might still show the original web page.

Configuration

In the settings of iCab under Bookmarks you can configure how many read items the reading list should keep. If there are more read items available, the oldest will be deleted.

Also the reading lots can be just stored locally within iCab, but also synchronized with the popular web services "Instapaper", so you can share the reading list with these services. When linking the reading list with these services, you have to provide the login credentials in the settings as well, so that iCab can load and save the reading list from and to this service.

In the iCloud settings the reading list can be also shared with other instances of iCab and iCab Mobile on other Macs, iPads and iPhones. This is especially useful if you also use iCab Mobile on the iOS platform.
