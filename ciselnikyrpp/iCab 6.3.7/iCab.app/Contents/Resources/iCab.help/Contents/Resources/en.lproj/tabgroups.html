Tab Groups

Tab Groups

All Tabs of a window can be saved as "Tab Group", so that this group can be re-opened anytime later again. When opening a tab group in a window, the current tabs of the window will be replaced by the tabs of the saved group. All changes within the opened Tab Group, for example opening links in a Tab, creating new Tabs or closing Tabs in the window will be automatically saved within the group. Therefore when opening the Tab group later again, it still includes all these changes.

Manage Tab Groups

Tab Groups can be managed using the menu item Tabs > Manage Tab Groups. This menu item opens a window which lists all the Tab Groups and their Tabs. It is possible to re-order the groups via Drag & Drop, also the individual Tabs can be reordered and moved between the groups. It's also possible to add new Tabs by dragging bookmarks, links etc into the window and place them in these groups.

Also all changes in already opened Tab groups will be directly reflected in the Tab Groups window.

Open Tab Groups

When double-clinking a group in the Tab Groups window you can open the Tab groups, double-clicking an entry of a tab opens the tab group as well but in addition activates this Tab.

In the menu Tabs of the menu bar all of the saved Tab Groups are listed as well and can be opened from there as well.

And another option to open Tab groups is through the sidebar of the browser window.

In all these cases you can hold down the Option key in order to open the Tab group in a new window. By default it will be opened in the current window and replaces all the Tabs which are already present in this window.

Tab Groups can be opened only once at the same time. So it you try to open aTab Group which is already open, the window if this Gropup will be simply brought into the foreground.

Save Tab Groups

All Tabs of the current window can be saved as Tab Group using the menu item Tabs > Add Tab Group.

You can do this from within the sidebar as well.

The menu item Tabs > Add Empty Tab Group or the corresponding item from the sidebar creates an empty Tab Group in the list of Tab Groups. This can be useful if you don't want to save the Tabs of an existing window as group, but manually create the group by adding bookmarks and links to the Group.

Additional features of the Sidebar

The sidebar of the browser window offers some additional features related to Tabs. The item 1 Tab can be used to directly replace all tabs of the window with a new (empty) Tab. This can be useful if the window contains several Tabs you don't need anymore and you want to start with a new Tab. This way you don't need to close all the Tabs manually and then open a new Tab.

The item Previous Tabs in the sidebar replaces the current Tabs of the window with the Tabs which were present in the window before opening a Tab group or the "1 Tab" option was used. This makes it possible to easily get back all the Tabs if you accidentally opened a Tab group in a window (replacing all the existing Tabs of the window). Also this Option allows to switch between two sets of Tabs fast and easily, without the need that these have to be saved a Tab group.
