Cookies & Almacenamiento Web

Muchas páginas web almacenan datos dentro del navegador, los cuales pueden ser leidos nuevamente por la página, la proxima vez que el usuario vuelve a visitarla. Estos datos son usados para multiples tareas, por ejemplo, para recordar las credenciales de usuario o el contenido del carrito de compras. Un navegador tiene diferentes tipos de almacenaminento como las Cookies, Bases De Datos, "Caches" entre otros.

Al seleccionar la opción de menú Herramientas > Almacenamiento Web se abrirá una ventana donde está todo el contenido de los diferentes tipos de almacenamiento y se donde puede inspeccionar. Es posible borrar los datos individualmente, por página web, tipo de almacenamiento y tambien se puede borrar todo.

Las Cookies tienen una opción especial, donde se pueden "proteger" individialmente marcandolas en una tabla. Las "Cookies" protegidas no seran borradas al instruir al navegador para que las borre, pero pueden ser borradas manualmente al seleccionarlas. Las "Cookies" protegidas son útiles si por ejemplo, quiere proteger las sesiones de usuario en algunas páginas pero quiere borrar otras para mantener la privacidad.
