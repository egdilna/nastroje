Administrador de Descargas

El Administrador de Descargas le permite descargar archivos individuales o incluso páginas web completas y guardarlas en el sistema de archivos para acceder a ellas sin conexión a Internet.

El elemento de menú Herramientas > Administrador de descargas abre la ventana del Administrador de Descargas, donde se listan todas las descargas (en progreso, finalizadas y pendientes). Las descargas seleccionadas se pueden iniciar, detener, eliminar y configurar mediante el menú contextual de los íconos de la barra de herramientas.

Las descargas se pueden iniciar de forma diferente:

Con el elemento de menú Archivo > Descargar, se puede crear una descarga manualmente. Usted mismo puede configurar la direccion URL y todos los parámetros de descarga. Si hace clic con el botón derecho del ratón sobre un enlace de una página web y selecciona la opciónDescargar Enlace en el menú contextual, se puede descargar el archivo enlazado.

Al hacer clic sobre un enlace a un tipo de archivo que iCab no puede mostrar, este se descargará en su computadora automáticamente.

Si mantiene pulsada la tecla Opción mientras hace clic sobre un enlace, iCab descargará el archivo inmediatamente.

Parámetros de descarga

Si crea una descarga manualmente usando el elemento de menú Archivo > Descargar o haciendo clic en el icono "Nueva descarga" de la ventana del administrador de descargas, puede configurar todos los parámetros de la descarga.

Todos estos parámetros tienen un valor predeterminado que se puede configurar en la seccion "Descargas" en el Panel de Ajustes de iCab. Por lo tanto, si necesita ciertos valores predeterminados para sus descargas, debe configurarlos primero en Panel de Ajustes para no tener que modificarlos cada vez que descarga un archivo.

El parámetro más importante es la direccion URL del archivo que se debe descargar. El destino de la descarga es la ubicación en su disco donde se guardará. Normalmente, es la carpeta "Descargas" de su almacenamiento principal.

En la ventana de diálogo de descargas, puede configurar si iCab debe descargar solo un archivo (opción predeterminada) o si debe descargar también todos los archivos enlazados desde el primer archivo (por ejemplo, para descargar una página web completa).

Descargar solo un archivo
Al seleccionar esta opción, se descargará solo 1 archivo. Este es el archivo especificado por la direccion URL. Esta es la configuración más común y se utiliza para descargar archivos (como software) de páginas web. No hay otros parámetros disponibles para este caso.
Descargar Todos los Archivos y Recursos Enlazados
Con esta configuración, puede descargar una página web completa, incluyendo "páginas anidadas", imágenes y otros archivos enlazados desde la página. Al hacer clic sobre el botón Configurar…, puede establecer varios límites para asegurarse de no descargar archivos innecesarios o de no descargar demasiados datos. Puede configurar los siguientes parametros:

Utilice la opción Destino para almacenar todos los archivos individualmente en la carpeta de descargas o guardarlos en un archivo comprimido ZIP.

También puede establecer límites, como el número máximo de archivos y datos que se descargarán, y el número de enlaces que se seguirán desde la página de inicio (profundidad del enlace). Si deja uno de estos campos vacío, no habrá límite para esta opción.

Es posible configurar iCab para que abra o no ciertos tipos de archivo. Muchos tipos de archivo comunes (imágenes, vídeo, audio, etc.) se pueden marcar o desmarcar directamente. iCab distingue entre archivos incrustados en la página web (como imágenes que se muestran directamente en la página web) y archivos enlazados.

También puede proporcionar una "Lista Separada por Comas" de las extensiones de archivo que deben descargarse (en la sección Incluir Extensiones) o los que no deben descargarse (Excluir Extensiones).

En la opción "Origen" se define dónde deben estar ubicados los archivos para descargar. Los archivos pueden estar en el mismo "dominio" de Internet que la página de inicio, en la misma "Carpeta" o dentro de toda la Internet (sin límites).

También puede definir nombres de dominiom, si desea excluir explícitamente archivos de estos Dominios de Internet, o si desea asegurarse de que los archivos solo provengan de ciertos Dominios de Internet especificos.
