Validador W3C

Desde iCab es posible usar el validador HTML y CSS de la W3C (Comite de Red Global de Telecomunicaciones World Wide Web) para obetener una lista de errores de las páginas que visita. Esta función es muy util para estudiantes, programadores e Ingenieros de Sistemas. Para buscar errores, seleccione el elemento de menú Herramientoas > Validador W3C HTML/CSS . Los resultados del validador se abrirán en pestañas nuevas (una para el código HTML y otra para el código CSS de la página web).

Tenga en cuenta que el Validador W3C necesita que el sitio web que quiere evaluar debe estar disponible en Internet. No pude revisar páginas guardadas localmente en su computadora.
