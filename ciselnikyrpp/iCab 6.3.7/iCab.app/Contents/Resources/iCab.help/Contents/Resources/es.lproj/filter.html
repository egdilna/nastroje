Administrador de Filtros

Administrador de filtros

El Administrador de filtros ubicado en el elemento de menú Herramientas > Administrador de Filtros) le permite bloquear ciertos elementos de las páginas web, como anuncios o programas de rastreo.

Los filtros se gestionan como Grupos de Filtros, cada uno contiene filtros que pertenecen al mismo grupo. Los grupos se pueden activar o desactivar individualmente y también se pueden exportar e importar, lo cual permite compartirlos con otros usuarios.

Filtros de Terceros

iCab permite listas de filtros populares como AdBlock Plus, uBlock, Easylist y compatibles. Puede descargar estas listas de filtros e importarlas con la función "Importar" para usarlas en iCab.

La ventana del Administrador de Filtros incluye algunos enlaces que abren pa2ginas de Internet donde puede encontrar listas de filtros populares de terceros. La mayoría de estas páginas incluyen enlaces especiales (normalmente con el nombre de "Añadir" o "Suscribirse" y la direcicon URL de estos enlaces tiene el esquema "abp:" en vez de "https:"). Al hacer clic, se ofrece directamente la importación de estas listas en iCab. Si no encuentra estos enlaces especiales, puede descargar manualmente la lista de filtros y luego importar el archivo de filtros mediante la función "Importar".

Activar/Desactivar Filtros

Los filtros se pueden activar o desactivar globalmente mediante el elemento de menú Visualización > Activar Filtros. También puede usar el ícono de "Filtrado" en la barra de Herramientas del navegador para activar o desactivar la función de filtrado (si el ícono no aparece puede configurar la Barra de Herramientas para añadir el ícono). En la ventana del Administrador de Filtros, también puede activar o desactivar colecciones individuales (e incluso dentro de las colecciones, puede activar o desactivar filtros individuales). De esta forma, puedes habilitar ciertos grupos de filtros solo cuando sean necesarias en casos de uso específico.

Si sospechas que un filtro está afectando a una página web que ya no funciona correctamente, es recomendable deshabilitar temporalmente los filtros de forma global (mediante el menú o el ícono de la Barra de Herramientas) y volver a cargar la página sin filtros. Si funciona, probablemente alguno de los filtros esté causando los problemas.

Crear Nuevos Filtros

Para crear un nuevo filtro, selecciona primero un grupo en la columna izquierda (puedes crear nuevos grupos con el botón + debajo de la lista de grupos). La lista de la derecha mostrará los filtros existentes del grupo seleccionado. Haga clic en el botón + debajo de la lista de filtros para crear un nuevo filtro. Se abrirá una ventana donde podrá configurar todos sus parámetros. Al hacer doble clic en un filtro existente también se abrirá la ventana para editar sus parámetros.

Se pueden usar los siguientes parámetros para definir un filtro:

Filtro
Aquí debe introducir la direccion URL del recurso al que se dirigirá el filtro. Si su objetivo son varios recursos y no uno individual, puede usar ciertos caracteres de uso multiple (subconjuntos de "expresiones regulares"). Sin estos caracteres de uso multiple o "comodínes", el filtro solo dirigirá a una sola direccion URL de un recurso específico. Con caracteres de uso multiple, puede generalizar un filtro para que se dirija hacia todos los recursos de un dominio de Internet, una ruta o incluso todos los recursos de toda la página. También puede decidir si las mayúsculas y minúsculas se tratan de forma diferente.
Acción
Esta opción define la función del filtro.
  • La opción "Bloquear Recurso" impide que se carguen los recursos que coinciden con el filtro (anterior).
  • La opción "Bloquear Cookies" bloquea las "Cookies" que coinciden con el filtro intenta establecer.
  • La opción "Ignorar Filtros Anteriores" ignora todos los filtros previos que coinciden con el filtro ubicado en el grupo de filtros. Esto puede ser útil si estos otros filtros podrian bloquear ciertos recursos, pero se quiere poner una excepción.
  • La opción "Ocultar Elementos de la Página" no bloquea todos los recursos, sino los elementos dentro de una página web que coincidan con un "Selector CSS". Al usar esta acción, debe definir el selector CSS para el o los elementos que quiere ocultar.
Recursos
Esta opción permite limitar el filtro a recursos propios (de la página web) o de terceros. Los recursos propios se refieren a aquellos que provienen del mismo dominio de Internet que el documento principal. Los recursos de terceros provienen de otros dominios de Internet. Si desea dirigirse hacia todos los recursos, utilice la opción de filtrado "Todos".
Tipo de Archivo
Estas opciones permiten especificar los tipos de archivo que el filtro debe bloquear.
Excepciones de dominio
Esta opción permite especificar los dominios de Internet de los que deben provenir o no los recursos o el documento principal a bloquear.

Exportar e importar

Para compartir filtros con otros usuarios, puede exportar colecciones de filtros a un archivo. También puede importar filtros.

Para exportar, primero seleccione todos los filtros que desee exportar y finalmente, haga clic en el botón "Exportar". Esto guardará las colecciones seleccionadas en un archivo.

Para importar filtros, haga clic en el botón "Importar" y seleccione el archivo que desee importar. Los grupos importados también aparecerán en la lista de colecciones.
