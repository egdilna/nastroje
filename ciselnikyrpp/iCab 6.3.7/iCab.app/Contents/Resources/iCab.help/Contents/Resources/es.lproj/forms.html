Llenado de Formularios

Administrador de Formularios

Al visitar las págias de Internet, a menudo necesitarás completar formularios donde debes ingresar repetidamente datos como, tu nombre, correo electrónico, contraseñas, etc. iCab ofrece diferentes maneras de ayudarte a completar estos formularios de Internet para que no tengas que ingresar los mismos valores repetidamente. Puedes guardar los valores de los formularios de Internet y completarlos más tarde con estos valores guardados. iCab también puede completar ciertos campos del formulario sin necesidad de haberlos guardado previamente. Incluso es posible que iCab complete automáticamente la información mientras escribes.

Todas estas funciones para completar formularios se pueden configurar en el Administrador de Formularios, que se abre mediante el elemento de menú Herramientas > Administrador de Formularios.

iCab guarda todos los datos de los formulario en la aplicación Llavero de MacOS. De esta forma, todos los datos se almacenan de forma segura y cifrada. Sin embargo, debe permitir que la aplicación de Llaveros almacene y recupere los datos del formulario. Al instalar una actualización de iCab, la aplicación de Llavero preguntará al usuario si la nueva versión de iCab puede acceder a los datos del formulario guardados por la versión anterior. Este comportamiento es normal y garantiza que ninguna aplicación nueva pueda acceder a datos confidenciales sin el permiso explicito del usuario.

El Administrador de Formularios cuenta con tres secciones, cada una con la configuración para diferentes métodos de rellenado de formularios. Cada sección se puede activar individualmente para que iCab intente rellenar automáticamente los formularios de las páginas web visitadas. Si el llenado automático de formularios está deshabilitado, puede iniciarlo manualmente desde el elemento de menú Visualización > Completar Formularios Esta función comprobará en cada pa2gina de Internet que visite si existen formularios que se puedan completar automáticamente.

Basado en Campos
Aquí puede configurar la función de llenado automático de formularios. Puede agregar cualquier cantidad de palabras y frases a la lista. En cuanto comience a escribir en un campo de un formulario de Internet, iCab buscará palabras y frases en esta lista que comiencen con las mismas letras que acaba de introducir. Si iCab encuentra una coincidencia, hará una sugerencia automáticamente con el texto encontrado. Por lo general, solo tiene que introducir dos o tres letras en un campo de entrada y iCab puede completar el resto.

Esta función es muy útil para toda la información que debe introducir en muchos formularios de Internet (como direcciones de correo electrónico, nombre, dirección postal, número de teléfono, etc.).

Esta función se puede utilizar en todos los formularios, incluso en aquellos que nunca se han visitado.

Basado en Claves
Aquí puede configurar la función de autocompletar, que se basa en los nombres de las claves de los campos del formulario. Por ejemplo, en la mayoría de los formularios, el campo de entrada donde debe introducir su nombre se llama dentro del código de funcionamiento "nombre". De este modo, iCab podría comprobar si un formulario contiene un campo llamado "nombre" y rellenar automáticamente su nombre. Esta función de autocompletado funciona en todos los formularios, incluso en aquellos que nunca ha visitado.

La lista de datos del formulario tiene dos columnas: la clave y el valor. La columna "clave" puede contener una lista de nombres separados por comas que representan los nombres (internos) de los campos de entrada. Dado que el nombre del campo no siempre es el mismo en todas las páginas web (por ejemplo, una página web puede usar "ciudad" y otra "pueblo" para un campo de entrada donde se debe introducir la localidad donde reside), basta con proporcionar una lista de nombres separados por comas con significados similares. Esto facilita la búsqueda de un nombre que realmente se use en la página web. La columna "valor" contiene el texto que deberia rellenarse.

Ejemplo:

ClaveValor
ciudad,puebloNueva York
paísEE. UU.
correo electrónico,mailmi.nombre@midominio.com
dirección, callePark Avenue 123

Tenga en cuenta que, incluso si la página web se encuentra en otro idioma distinto del inglés, los nombres internos suelen estar en inglés. Por lo tanto, siempre debe añadir nombres de clave en inglés a la lista.

Basado en Formularios
Esta función de autocompletado se utiliza para rellenar formularios de inicio de sesión. Para que funcione debe visitar la página web por lo menos una vez, completar el formulario manualmente y luego guardarlo usando el elemento de menú Visualizacion > Guardar Formulario. Los datos de los formularios guardados se mostrarán en el Administrador de Formularios. En cualquier momento puede editar la descripción, la direccion URL y el nombre de usuario.
