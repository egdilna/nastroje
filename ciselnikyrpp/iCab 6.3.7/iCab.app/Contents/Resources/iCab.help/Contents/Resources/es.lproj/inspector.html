Inspector

El elemento de menú Herramientas > Inspector Web abre una ventana donde usted puede ver e inspeccionar el código fuente de la página actual. Esta es una caracteristica interesante especialmente para los Desarrolladores de Software que les permite analizar la estructura de su página web. Esta característica requiere por lo menos MacOS 10.14 (Mojave)

El elemento de menú Herramientas > Recursos Web abre directamente la página de recursos del Inspector Web.

El elemento de menú Herramientas > Consola Web abre directamente la "Consola" del Inspector Web.
