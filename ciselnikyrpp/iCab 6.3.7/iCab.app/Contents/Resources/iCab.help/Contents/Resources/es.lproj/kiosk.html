Modo Quiosco

El modo quiosco es un modo especial en el que iCab bloquea el acceso al resto del sistema y otras aplicaciones, desactiva la barra de menú y solo muestra una ventana que cubre la pantalla. Este modo está diseñado para ciertos entornos, como por ejemplo, terminales de computadora ubicadas en lugares públicos (como terminales de información en estaciones de transporte, vestíbulos de hoteles, exposiciones, museos, etc.) que ofrecen información específica al usuario.

Los usuarios solo puede acceder a la información proporcionada, pero no al sistema ni a otra información de Internet.

El modo quiosco de iCab ofrece todo esto pero, también puede configurarse para que sea mucho menos estricto, si solo se utiliza en entornos privados donde no se necesitan muchas de las funciones de seguridad.

Activación del Modo Quiosco

El modo quiosco puede activarse mediante el elemento de menú Herramientas > Modo quiosco. Tiene la opción de proteger el modo quiosco con una contraseña, por lo que un usuario no podrá salir de este modo sin volver a escribir la contraseña correcta. Es posible deshabilitar la protección con contraseña, pero esto solo debe hacerse para uso privado, donde no se requiere ninguna protección especial del sistema.

Salir del Modo Quiosco

Para salir del modo quiosco, use el atajo de teclado Cmd + Mayúscula + K (Como la barra de menú no estará disponible en el modo quiosco, se debe usar una combinación de teclas).

Si el quiosco está protegido con contraseña, deberá ingresar la contraseña correcta para continuar.

Hay dos maneras de salir del quiosco: el botón Aceptar volverá al modo normal; el botón Salir hará que el navegador permanecerá en modo quiosco internamente y cerrará iCab para que pueda acceder de nuevo al Finder y al resto del sistema. Sin embargo, como la aplicación sigue en modo quiosco internamente, la próxima vez que se inicie iCab se activará en modo quiosco nuevamente.

Si desea asegurarse de que iCab permanezca en modo quiosco internamente incluso si alguien cambia accidentalmente al modo normal, puede hacer lo siguiente: Después de salir de iCab desde el cuadro de diálogo "Salir del Quiosco", busque el archivo ~/Library/Preferences/de.icab.iCab.plist en el Finder y protéjalo contra escritura haciendo clic derecho (o click izquierdo + tecla Opción) y activando el elemento de menú "Obtener Información". De esta forma, iCab ya no podrá modificar este archivo ni los ajustes, incluyendo el estado del modo quiosco.

Configuración del Modo Quiosco

En el panel de ajustes de iCab, encontrará una sección donde puede configurar el modo quiosco detalladamente.

Si la pantalla del terminal es táctil, es posible ocultar el cursor del ratón por completo. En estos casos, el cursor no es necesario, ya que el usuario utiliza su propio dedo para apuntar y hacer clic (tap). El teclado virtual es también es útil en estos casosm y se puede activar en el modo quiosco. Así, incluso sin un teclado conectado, el usuario puede digitar en los campos de los formulario o en el campo e dirección URL. El teclado virtual se muestra en la pantalla mediante un botón en la barra de herramientas. De esta forma, el usuario puede abrirlo o cerrarlo en cualquier momento.

Es posible desactivar el atajo de teclado para activar el modo quiosco. Esto puede ser útil si suele presionar accidentalmente este atajo de teclado pero no desea acceder al modo quiosco.

MacOS ofrece un atajo de teclado especial Cmd + Alt + ESC, que permite forzar el cierre de cualquier aplicación en ejecución. Esto no suele ser aceptable para una terminal de computadora pública, por lo que existe una opción para desactivar esta combinación de teclas, así como otros accesos directos del sistema como "Exposé", que podrían permitir el acceso a otras aplicaciones. Es posible activar o desactivar las barras de herramientas (barra de navegación, barra de favoritos, barra de estado, etc.) en el modo quiosco.

El modo quiosco tiene su propia página de inicio y se carga automáticamente cuando se ingresa al modo quiosco y cuando un usuario del quiosco finaliza su "sesión". La página de inicio del quiosco es una manera muy fácil de proporcionar un punto de partida bien definido para todos los usuarios del sistema quiosco.

Es posible agregar un botón "Fin de sesión" en la barra de herramientas del navegador. Este botón permite que un usuario termine manualmente su sesión para que iCab vuelva a la página de inicio del quiosco. También es posible definir un tiempo de inactividad. Esto significa que iCab volverá automáticamente a la página de inicio del quiosco, cuando la computadora estuvo inactiva durante un tiempo determinado (no hay actividad del usuario por un tiempo determinado), lo cual asume que ningún usuario está usando el quiosco en este momento. Esto ayuda y proteger a los usuarios a un si olvidan finalizar su sesión de usuario. Incluso es posible definir un temporizador que se que activa después de cierto tiempo, sin importar si la computadora está siendo usada o no. Esto solo es útil si desea limitar el tiempo en que cada usuario puede usar el modo quiosco o la terminal de computadora.

Todas estas características se pueden combinar y ser activas al mismo tiempo. Por razones de seguridad y privacidad, iCab también se puede configurar para eliminar todas las "Cookies", el historial y otros datos privados que se recopilaban dentro de una sesión, cada vez que iCab vuelve a la página de inicio del quiosco, ya sea usando el botón de "Finalizar Sesión" o un temporizador. Esto se hace activando la opción "Modo privado" para el quiosco.

La opción "Filtros" para el modo quiosco permite restringir el acceso solo páginas web específicas. Por lo tanto, los usuarios que intentan acceder a otras páginas que no están permitidas, recibirán un mensaje de error.

Al agregar una URL a la lista "Páginas Web Permitidas", puede usar el carácter asterisco "*" (que representa cualquier valor or caracteres de texto) y el símbolo de pregunta "?" (que representa cualquier cantidad de caracteres de texto) para que una direccion URL sea válida en una página web completa. Cuando no se usan estos caracteres, una direccion URL solo coincidirá con una sola página web. Por ejemplo, la URL "http://www.icab.de/" en la lista de páginas web permitidas, solo permitirá el acceso a esa página exacta. No se permitirán otras páginas anidadas porque estas tendrían una dirección URL diferente. Pero cuando se usa la dirección URL con un asterisco al final como "http://www.icab.de/*" en la lista de páginas web permitidas, se permitirá el acceso a todo el sitio web de iCab. El asterisco "*" al final de la direccion URL, hará coincidir todas las direcciones URL que comienzan con "http://www.icab.de/", por lo que también podría acceder por ejemplo a la dirección "http://www.icab.de/info.html", etc. Estos caracteres también llamados comodines facilitan la restricción a ciertas páginas web o incluso a ciertas carpetas dentro de ellas, sin necesidad de especificar una gran cantidad de páginas individuales, lo cual tomaría deamsiado tiempo.
