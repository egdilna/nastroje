Módulos

Módulos

Los Módulos son pequeños "Applets" los cuales pueden proveer un enlace mas comodo a los servicios de Internet como Administradores de Favoritos de terceros, páginas web de redes sociales donde pueden proeveer pequeñas herramientas genericas como por ejemplo mostrar todas las fotos de un sitio web.

Administrar Módulos

El elemento de menú Herramientas > Módulos > Administrador de Módulos abre una ventana donde usted puede configurar y administrar todos los módulos disponibles. Al marcar o remover la marca de los módulos puede agregarlos o quitarlos del menu. Tambien puede reordenar los módulos y tambien borrarlos completamente cuando lo necesite.

Al seleccionar un módulo en esta ventana se abrirán sus configuraciones para ajustarlos fácilmente.

La opción "Instalar Valores Predeterminados" vuelve a instalar los módulos predeterminados que se hayan perdido, en caso de que hayan sido borrados con anterioridad y los necesite nuevamente.

Activando Módulos

Los modulos pueden ser activados al seleccionarlos usando elemento de menú Herramientas > Módulos. Tambien como alternativa se puede hacer clic sobre su ícono en la Barra de Estado de la ventana del navegador. Cada módulo puede ser configurado para que se pueda acceder a el o no, mediante la barra de estado.

Programar sus Propios Módulos

Desde una perspectiva tecnica un módulo es solo un código ejecutable de Javascript, el cual es activado dentro del contexto de una página web cuando se activa. Son muy similares a los "bookmarklets" donde el código JavaScript se guarda como un Favorito y se activan seleccionándolos. La ventaja de estos módulos es que pueden tener sus propias configuraciones, y se puede acceder a ellos fácilmente desde el navegador usando su propio menú o la barra de estado, para usarlos masrapida y fácilmente. También es mas facil programarlos ya que no necesita codificarlos como si fueran una dirección URL lo que facilita su lectura y modificación.

Una explicación sobre como se pueden programar estos módulos se puede encontrar en el Blog de iCab.
