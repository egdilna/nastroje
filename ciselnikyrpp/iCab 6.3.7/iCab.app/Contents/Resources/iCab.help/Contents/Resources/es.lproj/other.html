Guardar Páginas Web

Cuando se guarda una página se puede escoger entre varios formatos de archivo diferentes.
Archivo Web (Safari)
Este formato de archivo es usado por Safari para guardar toda una página en un solo archivo, incluyendo imagenes y otros archivos externos. Este formato de archivo tiene la ventaja de que, el contenido de Internet dinamico de una página seguira estando disponible, ya que este archivo contendrá todo el código fuente de la página web.
Código HTML
Al usar este formato, iCab guarda únicamente el codigo HTML de la página web y nada mas, asi que las imagenes y los archivos externos no serán guardados.
Dirección
Esta opción guarda únicamente la dirección del sitio web. Al abrir powteriormente este arhcivo de dirección la página se cargará desde internet por lo que require que la página siga estando disponible y tenga conectividad a Internet.
PDF
Esta opción guarda la página como un archivo PDF junto con sus imagenes y formatos de texto pero es un archivo fijo sin interactividad.

Codificación de Texto

Las páginas Web puede ser hechas usando diferentes codificaciónes de texto como UTF-8, ISO-8859-1 entre otras. En general iCab puede determinar la codificación de texto automaticamente para mostrar el texto correctamente, pero hay algunas páginas en las que tal vez la codificación de texto no fue especificada en su código, y donde tal vez iCab no pueda determinarla automaticanete. En estos casos iCab usara la codificación de texto predeterminada que se puede configura al usar el elemento de menú Visualización > Codificación De Texto . Asi que, en el caso de que note en algunas páginas texto o caracteres incorrectos, puede intentar cambiar a otras codificaciones de texto hasta que se muestre adecuadamente.
