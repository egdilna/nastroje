Detección de Fraude Tipo Phishing y Malware

Usted puede activar la detección de fraude de tipo Phishing y/o Malware en la sección Seguridad del panel de ajustes de iCab.

Esta funcionalidad utiliza la detección de Phishing y Malware provista por Google. Cada vez que abre una página web iCab busca la página en la base de datos de sitios reconocidos de practicar fraude y contener malware. Si ese fuera el caso, iCab no mostrará la página y advertirá al usuario. El usuario puede en cualquier caso abrir dicha página si así lo desea, haciendo clic en el botón correspondiente en el aviso advertencia.

Todas las verificaciones se realizan dentro de iCab, asi que Google no recibirá ninguna información de los sitios que usted visita. iCab solo necesita mantener actualizada la base de datos de sitios fraudulentos de forma regular. (esto se hace mediante una operacion matemática llamada suma de verificación o de valores "hash")
