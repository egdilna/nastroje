Ajustes

Use el elemento de menú iCab > Ajustes para configurar todos los aspectos del navegador.

General

Página de Inicio, Página de búsqueda
La Página de Inicio y la Página de Búsqueda, son dos páginas web que pueden ser definidas por el usuario, estas páginas web se pueden abrir rápidamente usando ciertos botones de la Barra de Herramientas en la ventana del navegador. Estos sitios también se pueden cargar automáticamente al abrir ventanas o pestañas nuevas.

La Página de Inicio suele ser cualquier página web que visitas amenudo al iniciar la navegación, mientras que la página de búsqueda suele ser la página web de tu motor de búsqueda preferido. Por supuesto, puedes configurar cualquier página web que desees para ambas opciones.

Programas Predeterminados
En esta sección puedes definir el navegador de Internet predeterminado, la aplicación de correo electrónico predeterminada, la aplicación de FTP predeterminada, etc. Estas configuraciones no son específicas de iCab sino que son globales de MacOS.
Código fuente
iCab puede mostrar el código fuente de una página web usando el elemento de menú Visualización > Código Fuente. iCab, ademas de mostrar el código fuente en si mismo, le ofrece dos formas de hacerlo: mostrar el código fuente exactamente como esta definido en página web o puede colorear las etiquetas HTML. El código fuente se puede abrir en un editor de texto externo (el que esté configurado como editor de texto predeterminado).
Sugerencias de Direcciones
Al introducir una dirección de Internet o un término de búsqueda en el campo de dirección, iCab puede mostrar sugerencias de direcciones y términos de búsqueda. Al seleccionar una de las sugerencias se puede agilizar el proceso, ya que no es necesario que escriba la dirección o el término de búsqueda completamente. La configuración de las sugerencias de direcciones le permite indicarle a iCab de dónde deben provenir las sugerencias y cuántas sugerencias deben mostrarse.
Transferencia
La función Transferencia de MacOS le permite iniciar una sesión de navegación en un computador, iPad o iPhone y continuarla en otro ordenador o dispositivo diferente. iCab soporta esta función cuando está habilitada para ventanas y pestañas, lo que le permite controlar todas las pestañas y ventanas de iCab en otra Mac o en iCab Móvil en iPhone y iPad.

Al trasferir una sesión desde otro computador o dispositivo en este computador, se puede configurar si las ventanas y pestañas del otro ordenador o dispositivo deben reemplazar las pestañas y ventanas existentes o si deben abrirse además de las ventanas ya existentes.

Menú Contextual
El Menú Contextual (al hacer clic en un enlace o imagen con el botón izquierdo del ratón mientras mantiene presionada la tecla Control, o al hacer clic con el botón derecho del ratón) puede tener una gran cantidad de opciones para abrir para enlaces, imágenes, marcos, etc., ya que todas las formas posibles de abrirlos se mostrarán en este menú. Esto significa que tiene la opción de abrir un enlace en la pestaña actual (de forma similar al hacer clic en el enlace normalmente) y también todas las opciones disponibles, como abrirlo en una nueva ventana o pestaña, en primer plano o en segundo plano y opciones para descargar el archivo enlazado entre otras. Lo mismo ocurre con las imágenes y los marcos, si haces clic en ellos. Por lo tanto, el menú puede resultar extenso y tener muchas entradas, lo que haría dificil su manejo.
La opción compactar proporciona un menú más compacto, donde muchas de las entradas están ocultas de forma predeterminada. Las acciones principales (como abrir un enlace normalmente en la pestaña o ventana actual) siempre estarán visibles, pero en lugar de mostrar todas las opciones para abrir un enlace, solo se muestra una opción (la predilecta, según la configuración de "ventana/pestañas"), y al presionar la tecla Mayuscula y/o la tecla Opción muestra una opción diferente (la tecla La tecla Opción alterna entre abrir una ventana o pestaña nueva. Esto reduce el tamaño del menú, pero mantiene todas las opciones accesibles cuando se necesiten.

La opciones alternativas a la que se accede de forma predeterminada sin pulsaciones adicionales se determinan mediante la configuración de ventanas/pestañas, que controla si se prefieren las pestañas en vez de las ventanas y si se abren en primer plano o en segundo plano.

Confirmaciones
En muchas partes de la aplicación usted puede seleccionar y eliminar varios elementos a la vez (Marcadores, Historial, Descargas, etc.). En la opción "Confirmaciones", puedes configurar si iCab debe solicitar confirmación adicional para las operaciones de eliminación, y si esto debe realizarse solo cuando se elimina un número determinado de elementos simultáneamente.

Al tener que confirmar cada operación de eliminación, o solamente las operaciones de borrado mas extensas, se puede evitar que elimine algo por accidente, pero también puede hacer algo mas lento el proceso de eliminación de elementos al requerir confirmación.

Código QR
En casi todos los lugares donde puede encontrar un menú contextual para direcciones de Internet (enlaces, marcadores, historial, descargas, etc.), puede también obtener un elemento de menú para generar un código QR de la dirección URL. Los códigos QR son códigos de barras 2D muy populares que contienen enlaces a todo tipo de datos y son especialmente útiles para dispositivos móviles.

Estos códigos se pueden escanear fácilmente con la cámara integrada, evitando tener que escribir direcciones de Internet con el teclado del smartphone. Por lo tanto, la opción de código QR en iCab puede ser útil si a veces necesitas pasar una dirección de iCab a un smartphone, por ejemplo para abrir una página web. Si no necesitas la opción de código QR, puedes desactivarla para mantener el menú contextual más pequeño.
El código QR se puede guardar como imagen simplemente arrastrándolo al escritorio de MacOS.

Ventanas

En esta sección puedes configurar todo lo relacionado con las pestañas y ventanas.
Nueva Centana/Pestaña Muestra...
Esta opción define lo que se muestra en todas las ventanas o pestañas nuevas. La ventana puede estar vacía o mostrar la Página de Inicio, la página de búsqueda y los favoritos (el contenido de la Carpeta de Favoritos o los Favoritos).
Al Iniciar la Aplicación
Esta opción define lo que se muestra después de iniciar la aplicación. La configuración predeterminada sería cargar la "Última sesión (restaurando todas las pestañas)", lo que garantiza que se restauren todas las ventanas y pestañas que estaban abiertas al cerrar la aplicación por última vez. Pero también es posible abrir solo la Página de Inicio, la página de búsqueda, los favoritos o ninguna.
Activación de la Aplicación
En caso de no haber ventanas abiertas cuando se abre la aplicación, esta opción define si la aplicación debe abrirse y qué debe abrirse .
Otras Aplicación Abren Una Página en iCab
Si otra aplicación abre una página web en iCab, esta página puede abrirse en la ventana o pestaña actual, o en una nueva.
Opciones para ventanas/pestañas
La opción de preferir pestañas en vez ventanas permite que, cada vez que una página web intente abrir una nueva ventana, iCab abrira una pestaña nueva. Además, los atajos de teclado para abrir ventanas o pestañas nuevas utilizarán los atajos de teclado más cortos para las pestañas. La opción de abrir ventanas o pestañas en segundo plano también afectará la forma en que se abren las ventanas y pestañas y asignará los atajos de teclado más cortos según sus preferencias.

Aquí también se muestran los atajos asignados actualmente a las diferentes formas de abrir nuevas ventanas o pestañas. Estos atajos se pueden usar en las páginas web al abrir enlaces, pero también al abrir los Favoritos desde el menú o la ventana.

Requerir Confirmación
En los casos en que deba abrir o cerrar muchas ventanas o pestañas a la vez, iCab puede solicitar confirmación al usuario. Esto ayuda a evitar el cierre accidental de una ventana que contenga varias pestañas abiertas o abrir una carpeta completa de marcadores.
Componentes de la Ventana
La Barra de Estado de la ventana del navegador se puede activar o desactivar. Al desactivarla hay más espacio disponible para la página web. La activación proporciona información adicional sobre el destino del enlace sobre el que reposa el cursor del ratón. La barra de estado también facilita el acceso a ciertos módulos.
Archivos de Sesión
La función "Sesión" permite guardar la sesión de navegación actual (todas las ventanas y pestañas) en un archivo y, al cargar este archivo mas adelante, le permite restaurar todas las ventanas y pestañas. Al cargar un archivo de sesión, es posible reemplazar todas las pestañas y ventanas existentes con la nueva sesión que se está cargando, o cargar la sesión adicionalmente a las ventanas y pestañas existentes (lo que significa que las ventanas y pestañas existentes se mantienen abiertas).

Favoritos

En esta sección puede configurar todo lo relacionado con los Favoritos, el historial y la lista de lectura.
Marcadores
Todos los Favoritos están disponibles en el elemento de menú Favoritos y se abren seleccionando los elementos dentro de el. Si desea abrir todos los marcadores de una carpeta a la vez, puede añadir la opción "Abrir como pestañas" a todos los menus anidados del menú de Favoritos. Esta opción abrirá todos los marcadores de esta carpeta al mismo tiempo como pestañas. La opción para mostrar la "Barra de Favoritos" mostrará una barra de herramientas especial en cada ventana del navegador donde se pueden acceder directamente a todos los favoritos.
WebDAV
Los Favoritos se pueden guardar opcionalmente en un servidor WebDAV. Esto puede ser útil si utiliza varios Mac y desea tener los mismos Favoritos en todos los computadores. iCab cargará o actualizará automáticamente los Favoritos desde el servidor WebDAV cuando la opción esta activada y también almacenará todos los cambios en los Favoritos en dicho servidor. Esta función requiere introducir la dirección URL completa del archivo de Favoritos, donde debería estar ubicado en el servidor WebDAV.

Una forma alternativa de sincronizar los marcadores es usar la sincronización de iCloud (consulta la configuración de iCloud).

Historial
Mientras navega por internet iCab guarda un historial de las páginas web visitadas. Este historial se puede eliminar automáticamente al salir de iCab. También puedes configurar cuántas páginas web se deben almacenar en el historial y durante cuántos días. Cuando se alcanza cualquiera de estos límites, iCab eliminará los registros más antiguios del historial. También hay un botón para eliminar el historial inmediatamente.
Lista de lectura
La lista de lectura es un tipo especial de lista de Favoritos, donde los Favoritos solo se almacenan temporalmente hasta que son leídos. La lista de lectura puede almacenarse localmente, pero también se puede enlazar de forma opcional con una cuenta de “Instapaper”. Si la lista de lectura se utiliza con estos servicios de terceros debes iniciar primero sesión en la cuenta de estos servicios dentro de los ajustes de iCab. Normalmente, la lista de lectura solo conserva sus registros hasta que se leen, pero puedes configurar cuántos marcadores ya leídos se deben conservar.

Páginas Web

En esta sección se puede definir el contenido y los permisos permitidos para una página web.
Contenido Web
Aquí puede configurar la tecnología (JavaScript, Java, plugins, etc.) que puede usar una página web.

En general, puede usar la tecla Tab para navegar entre los campos de texto de una página web. También es posible navegar entre enlaces y campos de texto.

En caso de que la carga de una página web se pueda diferir y esté abriendo varias pestañas a la vez, iCab solo cargará la pestaña activa (visible) inmediatamente; las demás pestañas solo se cargarán cuando hagan visibles o entren en primer plano.

Reproducción de Audio/Vídeo
La opción "Detener la Reproducción de Audio/Vídeo en Segundo Plano" se asegura de que solo la ventana o pestaña activa pueda reproducir contenido de Audio o Vídeo. En cuanto la ventana o pestaña activa pase a segundo plano, la reproducción de Audio o Vídeo se detendrá automáticamente.

También se puede configurar que el usuario debe iniciar manualmente la reproducción de Audio o Vídeo, para que las páginas web no lo hagan automáticamente.

Hojas de Estilo Definidas por el Usuario
Puede configurar sus propias "Hojas de Estilo CSS", que puede activar o desactivar en cualquier momento mediante el elemento de menú Visualizacion > Hojas de Estilo Definidas por el Usuario. Estas Hojas de Estilo permiten manipular y cambiar el diseño de las páginas web. Nota: esta función requiere conocimientos programación de HTML y CSS.
Tamaño de fuente
Esta opción permite definir el tamaño mínimo de fuente que debe utilizarse para el contenido de las páginas web .
Codificación de Texto
Cada página web utiliza una "Codificación de Texto" específica para mostrar caracteres específicos del idioma. Una codificación común es UTF-8, pero también se utilizan muchas otras. Normalmente, una página web indica al navegador qué codificación debe usar, para que este pueda usar la codificación correcta. Si una página web no lo hace, iCab utiliza la codificación predeterminada. Por lo tanto, si una página web muestra caracteres o letras que le parezcan incorrectas, puede intentar otras codificaciones de texto hasta que los caracteres se vean adecuadamente.
Sonido al Cargar la Página
iCab puede reproducir un sonido al terminar de cargar una página web. Esto puede ser especialmente útil para usuarios con ceguera.

Redes

Cookies
Es posible permitir que las páginas web usen "cookies" o bloquearlas todas. Las "Cookies" también se pueden eliminar automáticamente al salir de la iCab. Si necesita más control sobre las "Cookies", puede usar la función de filtros para bloquearlas según el dominio y la dirección de Internet.
Almacenamiento Web
Las páginas web no solo pueden almacenar datos en el navegador usando Cookies, sino que también existen otros tipos de almacenamiento (almacenamiento web, bases de datos, cachés, etc.). Estos también se pueden configurar para que se borren automáticamente al salir de la iCab.
Identidad del Navegador
Muchas páginas web ofrecen diferentes versiones de sus páginas para distintos navegadores y sistemas operativos. Estas páginas pueden proporcionar información o archivos diferentes según el navegador o pueden evitar el uso de navegadores alternativos. Por lo tanto, iCab puede reportar una Identidad de Navegador diferente a las páginas web, lo que hace que las páginas asuman que iCab es otro navegador. Esto puede ayudar a obtener otro contenido, como descargas especificas para otros sistemas operativos o una versión funcional de la página.
Identidades Definidas por el Usuario
Si las Identidades de Navegador predefinidas en iCab no incluyen la Identidad que necesita, puede definir sus propias Identidades. Estas se pueden seleccionar posteriormente para ser predeterminadas al igual que las predefinidas.
Identidades Específicas Para páginas web
Si visita regularmente varios páginas que requieren un Identidad de Navegador diferente, puede definir Identidades de Navegador específicos para estos sitios. Estas Identidades se usarán solo en aquellos sitios cuya dirección URL coincida con el filtro de direccion URL definido para cada Identidad. Puede usar caracteres comodín (*, ?, [abc]) para que varias direcciones URL coincidan con un solo filtro.

iCloud

Varios archivos de iCab se pueden sincronizar con otras instancias de iCab (Mac) e iCab Móvil (iPad y iPhone) a través de iCloud. Esto significa que cada cambio en un computador o dispositivo estará disponible automáticamente en los demás.

Al sincronizar datos, siempre se sincroniza la copia más reciente de todos los computadores y dispositivos, por lo que se escribirá encima de las versiones anteriores de estos archivos. Este es el comportamiento normal de una sincronización.

Si tiene datos almacenados en distintos computadores y dispositivos y no desea perderlos, puede activar la opción "Combinar" antes de activar la sincronización para este tipo de datos. iCab cargará primero los datos existentes de iCloud, los combinará con los datos locales y luego guardará los datos combinados en iCloud, los cuales se copiarán a todos los demás dispositivos. Luego de la combinación de datos iCab desactivará automáticamente la opción "combinar" para para que la sincronización normal entre dispositivos ocurra.

Búsqueda

Sugerencias de Búsqueda
Mientras ese escribe texto en el campo de dirección o de búsqueda, iCab puede sugerir términos de búsqueda solicitándole a un motor de búsqueda los términos de búsqueda populares. Aquí puede configurar el motor de búsqueda que iCab debe usar para solicitar sugerencias.
Motores de búsqueda
En esta lista, iCab almacena todos los motores de búsqueda que se pueden utilizar al iniciar una búsqueda en internet desde el campo de dirección o de búsqueda en la ventana del navegador. Puede asignar un carácter "clave" para cada motor de búsqueda, que se puede utilizar en el campo de dirección para especificar un motor de búsqueda (escribiendo el carácter clave seguido de un espacio y finalmente, el término de búsqueda).

Al definir una entrada para un nuevo motor de búsqueda, puede utilizar la cadena de texto "%@" como sustituto del término de búsqueda. Esta cadena se reemplazará automáticamente por el término de búsqueda al realizar la búsqueda. Si la cadena "%@" no aparece en la dirección URL, iCab simplemente añadirá el término de búsqueda al final de la dirección URL.

Motor de búsqueda predeterminado
Utilice este menú para seleccionar el motor de búsqueda predeterminado que se utilizara cuando no se selecciona ningún motor de búsqueda explícitamente.

Descargas

En la configuración de descargas puede configurar los ajustes predeterminados para todas las descargas nuevas. Estos ajustes se pueden modificar al crear una descarga manualmente en caso de que cada descarga requiera ajustes diferentes.

iCab dispone de los siguientes ajustes generales:

Carpeta de Descargas
Todas las descargas se guardarán en esta carpeta. iCab utiliza la carpeta "Descargas" estándar de MacOS de forma predeterminada.
Al Finalizar la Descarga
Estas opciones controlan las acciones que iCab realiza después de finalizar correctamente una descarga. El registro de una descarga en la ventana de "Descargas" se puede eliminar automáticamente (excepto si la descarga no se pudo finalizar debido a un error), por lo que solo se muestran las descargas sin finalizar. Además, al finalizar la última descarga la ventana de descargas se puede cerrar automáticamente. iCab puede emitir un sonido para informarle sobre las descargas finalizadas.
Al Iniciar la Aplicación
Esta opción controla si se abrirá la ventana de descargas y cuándo se abrirá después de iniciar la aplicación. Por ejemplo, la ventana de Descargas se puede abrir si hay descargas sin finalizar como notificación al usuario.
Existen ajustes adicionales para la función "Descarga de páginas de Internet", donde iCab puede descargar páginas web enteras, incluyendo subpáginas y recursos incrustados:
Formato
Utilice el ajuste de Formato para almacenar todos los archivos individualmente en la carpeta de descargas o guardarlos en un archivo comprimido ZIP.
Origen
La opción "Origen" define dónde deben estar ubicados los archivos para ser descargados. Los archivos pueden estar en el mismo dominio que la Página de Inicio, en la misma carpeta o dentro de toda la página de Internet (sin límites).
Profundidad Máxima, Número de Archivos, Tráfico
También puede establecer límites como el número máximo de archivos y datos que se deben descargar, y el número de enlaces que se seguirán desde la Página de Inicio (profundidad de enlaces). Si deja uno de estos campos vacío, no hay límite para esta opción.
Archivos Incrustados, Archivos Enlazados
Es posible configurar iCab para que cargue o no ciertos tipos de archivos. Muchos tipos comunes de archivos (imágenes, vídeo, audio, etc.) se pueden marcar o desmarcar. iCab puede distinguir entre archivos incrustados en la página web (como imágenes que se muestran directamente en la página) y archivos enlazados.
Incluir/Excluir Extensiones de Archivo
También puede proporcionar una lista separada por comas de las extensiones de archivo para los archivos que deben descargarse (Incluir Extensiones) o los que no deben descargarse( Excluir Extensiones).
Incluir/Excluir Dominios
También puede definir nombres de dominio si desea excluir explícitamente archivos de estos dominios o si desea asegurarse que los archivos solo provengan de ciertos dominios.

Seguridad

Nombres de Dominio Internacionales (IDN)
Los Nombres de Dominio Internacionales (IDN) son nombres de dominio que pueden contener letras y símbolos específicos de cada idioma. Sin embargo, muchos idiomas tienen letras muy similares o incluso idénticas a las de otros idiomas, lo que puede generar confusión o incluso ser usados por delincuentes para falsificar páginas legitimas. La opción mostrar solo IDNs seguros puede utilizarse para garantizar que los IDN con estos caracteres confusos no se muestren en su forma engañosa.
Advertencias de Fraude Tipo Phishing y Malware
iCab puede advertir al usuario antes de visitar páginas web que pueden ser peligrosos ya que intentan robar contraseñas (phishing) o proporcionan software malicioso (malware). iCab utiliza un servicio de Google para esta función. Google proporciona una extensa base de datos de todos las páginas fraudulentas conocidas de Internet con Malware y Phishing, por lo que iCab puede buscar en ella cada vez que se abre una nueva página web. El uso de la base de datos es anónimo, por lo que Google no obtiene información sobre las páginas web que usted visita. La base de datos contiene valores "cifrados" de todos las páginas fraudulentas y se almacena localmente en tu Mac (y se actualiza periódicamente). Por lo tanto, iCab también puede comprobar localmente en tu Mac si la dirección URL (o su valor hash) que va a visitar se encuentra en esta base de datos.
Certificados
Todos los certificados necesarios para comprobar la seguridad y el cifrado de las páginas web se almacenan y gestionan mediante la aplicación "Administrador de Llaveros" de MacOS. Puedes acceder al "Administrador de Llaveros" directamente desde la configuración.

Si visita páginas web donde MacOS no puede comprobar la validez de los certificados (por ejemplo, certificados autofirmados, caducados inválidos o no confiables), iCab mostrará una advertencia. Esta advertencia incluye el motivo del problema y las opciones para visitar la página si asi lo desea o para detenerla. El usuario puede decidir si esta seleccion será permanente; de ​​esta manera, en el futuro, la advertencia se omitirá y la página se visitará o bloqueará automáticamente, o si en futuras visitas se mostrará la misma advertencia.

Si la advertencia se responde con una decisión permanente, puede usar el botón Editar Dominios de Confianza para cambiar esta decisión.

La opción Bloquear Automáticamente Certificados NO Confiables permite bloquear automáticamente todas estas advertencias sobre certificados, de forma que iCab nunca visite estas páginas y tampoco muestre ninguna advertencia.

Quiosco

El modo Quiosco es un modo especial en el que iCab bloquea el acceso al resto del sistema, ocultando la barra de menú y ocupando toda la pantalla. Este modo está especialmente diseñado para terminales de información pública, donde el usuario debería poder obtener cierta información, pero no debe acceder a otros programas ni al sistema.
General
Es posible deshabilitar el atajo de teclado para habilitar el Modo Quiosco. Esto puede ser útil para evitar que se active accidentalmente.

MacOS ofrece varios atajos de teclado para forzar el cierre de aplicaciones, activar la función "Exposé", etc. Dado que estos atajos permiten acceder al sistema o cambiar a otras aplicaciones, también se pueden desactivar en el Si el Quiosco no tiene un teclado físico, pero el usuario debería poder escribir texto, se puede habilitar el "Teclado Virtual". Esto añadirá un elemento de menú a la Barra de Herramientas del navegador que permite abrir un teclado virtual.

El cursor del ratón se puede ocultar si no es necesario, por ejemplo, si el Quiosco tiene una pantalla táctil.

Se puede añadir el botón Finalizar Sesión a la Barra de Herramientas del navegador. Este botón permite al usuario cerrar la sesión explícitamente. Esto cargará de nuevo la Página de Inicio del quiosco y eliminará todos los datos privados (cookies, cachés, etc.) si el modo privado del quiosco también está habilitado.

Barras de Herramientas del Navegador
La barra de estado y la barra de favoritos se pueden activar o desactivar para el quiosco independientemente del modo de uso normal del navegador.
Página de Inicio del quiosco
La Página de Inicio del quiosco se cargará después de activarlo y también cada vez que se cierre una sesión (ya sea por accion directa del usuario o automáticamente después de un tiempo determinado, ver más abajo).
Opciones del quiosco
La Página de Inicio del quiosco se puede programar para cargarse automáticamente después de un tiempo de inactividad. Esto es útil si un usuario del quiosco siempre debe iniciar sesión desde la Página de Inicio. Incluso si un usuario no cierra la sesión manualmente, iCab puede volver a la Página de Inicio al usar el temporizador de inactividad. Incluso es posible imponer un cierto lapso de tiempo después del cual se cargará nuevamente la Página de Inicio, independientemente de si la aplicación está o no en uso.

El "Modo Privado" del quiosco controla si se deben eliminar todos los datos privados (cookies, cachés, etc.) al cargar la Página de Inicio.

Filtros
Puede proporcionar una lista de direcciones URL (se permite usar caracteres comodín) que limiten las páginas web que se pueden visitar en el quiosco. Si esta función está habilitada, solo se podrán visitar las direcciones URL que coincidan con los filtros de la lista.
