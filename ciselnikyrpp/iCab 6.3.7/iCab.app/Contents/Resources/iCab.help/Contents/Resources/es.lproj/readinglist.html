Lista de Lectura

La Lista de Lectura le permite guardar páginas web para ser leídas mas adelante. Es similar a los Favoritos, pero su función no es guardarlas permanentemente sino hasta que el usuario las haya leído. La lista de lectura consiste de tres vistas: las páginas sin leer, páginas leídas y todas las páginas. La lista de lectura solamente puede salvar cierta cantidad de páginas así que las páginas con mas antigüedad serán removidas automaticamnte.

La Lista de Lecturaa puede se puede abrir usando el elemento de menú Herramientas > Lista de Lectura . El botón+ puede ser usado para agregar la página en la que se encuentra a la Lista de Lectura lo cual también es posible usando el elemento de menú Visualización > Agregar a Lista de Lectura.

Al hacer clic en un registro se abrirá la página en el navegador y se moverá automaticamente a la lista de elementos "leidos".

Modo de Lectura

Si usted hace clic en el ícono en forma de "lente" en la lista de lectura, la página web se abrirá en el Modo de Lectura. Este modo removerá de forma temporal de la página web todo lo que distraiga del contenido principal, como publicidad menús etc., para hacerlo mas fácil la lectura.

El Modo de Lectura tambien puede ser activado independientemente de la Lista de Lectura usando el elemento de menú Visualización > Modo de Lectura .

Muy Importante: El Modo de Lectura solo funciona en páginas web que contengan un solo artículo o texto principal. En caso de que iCab no detecte ningun artículo de lectura se mostrará la página original.

Configuración

En los ajustes de iCab en el panel de Favoritos puede configurar el número elementos que se deberán almacenar. Si se agregan mas elementos, los mas antiguos se borrarán.

No solo es posible almacenar lotes de elementos de lectura dentro de iCab, sino que también se puede sincronizar con servicios populares como "Instapaper". De esta forma usted puede compartir las Listas de Lectura con estos servicios. Al enlazar la lista de lectura con estos servicios, usted deberá proveer las credenciales de inicio de sesión en los ajustes e iCab, de esta forma iCab puede cargar la lista de lectura desde y hacia estos servicios.

En los ajustes de iCloud la Lista de Lectura puede ser compartida también con otras instancias de iCab y iCab Movile en otros Macs iPads y iPhone. Esto es especialmente útil si usa iCab también en la plataforma de móvil de iOS
