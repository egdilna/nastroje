Búsquedas

Buscar en Internet usando el campo de búsqueda

La ventana del navegador puede configurar para que tenga un campo texto permanente ubicado en la barra de herramientas que permitte buscar en diferentes motores de búsqueda. Utilice el elemento de menú Visualización > Personalizar barra de herramientas para configurar la barra de herramientas y agregar o remover el campo de búsqueda si asi lo desea.

Para iniciar una búsqueda simplemente escriba las palabras en el campo de búsqueda y presione la tecla Retorno. Al hacer clic en el ícono a la izquierda del campo de texto se abrirá un menú emergente donde puede seleccionar el motor de búsqueda que desee usar. Mientras ingresa el término de búsqueda iCab mostrará una lista de sugerencias donde puede directamente seleccionar el término de busqueda.

Buscar en Internet Usando el Campo de Dirección

Usted también puede usar la barra de direcciones para hacer búsquedas, así que el campo de búsqueda dedicado no es realmente necesario. Cuando usted escribe algún texto en el campo de direcciones pero este no se puede abrir como una página de Internet, el texto sera tratado como un término de búsqueda. iCab usará el motor de búsqueda predeterminado para la búsqueda en el campo de direcciones, pero usted puede seleccionar otro motor de búsqueda, si usted ingresa una clave (combinación de letras) que haya sido asignada para un motor de búsqueda especifico, en los ajustes de los motores de búsqueda, seguido por un espacio y el término de búsqueda. Por ejemplo la clave "g" es asignada a "Google" y la "w" a "Wikipedia", así que al escribir "g prueba" se buscará la palabra "prueba" en Google y al escribir "w prueba" buscara la palabra "prueba" en Wikipedia. Si solo escribe "prueba", se buscará usando el motor de búsqueda predeterminado configurado en los ajustes.

Buscar la Selección de Texto Actual

Si usted selecciona una palabra o frase en una página de Internet y luego selecciona el elemento de menú Editar > Buscar > Buscar Selección en Internet, iCab buscara el texto seleccionado usando el motor de búsqueda predeterminado (El mismo que se usa en el campo de búsqueda). El resultado sera luego mostrado en una pestaña o ventana.

Buscando en la Ventana Actual

Puede usar el elemento de menú Edición > Busqueda > Buscar (atajo de teclado Cmd + F) para buscar el texto seleccionado dentro de la ventana actual. Una pequeña barra de búsqueda se abrirá donde usted podrá escribir un termino de búsqueda. Los resultados de la búsqueda se marcarán en color amarillo en la página web en uso y puede usar las flechas en el teclado para moverse entre las coincidencias del termino de busqueda.

Configurando la Búsqueda en Internet

Los motores de búsqueda usados en el campo de búsqueda o el campo de dirección pueden ser configurados en el panel de ajustes Búsquedas. Allí puede agregar nuevos motores de búsqueda o borrar los existentes que no necesite. También puede cambiar las palabras clave que pueden ser usadas en el campo de dirección para especificar el motor de busqueda.
