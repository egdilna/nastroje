⛓️ [Vizuální JSON editor](https://nastroje.egdilna.cz/json) je intuitivní webový editor pro prohlížení a úpravu JSON dat bez psaní závorek a uvozovek. Hodí se na konfigurační soubory, odpovědi API i jiné datové struktury. Online běží na https://nastroje.egdilna.cz/json

## Hlavní funkce

* Vizuální úpravy ve stromové struktuře (bez ruční syntaxe)
* Automatická validace datových typů
* Načítání ze souboru, ze schránky nebo z URL (komprimovaná data pro sdílení)
* Plně přístupný (podpora čteček obrazovky)
* Vícejazyčné rozhraní (CS/EN)
