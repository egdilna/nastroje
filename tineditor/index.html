Bez načteného TIN

Nástroj pro práci s TIN soubory: načtení, validace proti schématu 1.0, minifikace, přenos přes schránku a generování ekvivalentu system promptu v Markdownu.

1. Zdrojový TIN (JSON)

Textarea pro TIN JSON. Použijte tlačítka pod polem pro načtení, ověření nebo zpracování.

2. Výsledek validace

Zatím nic. Klikni na Ověřit proti schématu.

3. Vygenerovaný system prompt

Sestavení ekvivalentu system promptu pro model, který TIN neumí interpretovat nativně. Prompt vzniká dekompozicí TIN na role, hranice, aktivní pravidla, kontext, materiály a tvar výstupu.

Vygenerovaný Markdown text připravený k vložení jako system prompt.

O aplikaci a schématu

Aplikace pracuje se schématem TIN 1.0 vestavěným přímo v HTML souboru — nepotřebuje internet ani externí knihovny. Validace kontroluje strukturu, povinná pole, typy a základní vzory (semver, MIME-like jazyk výstupu, ISO jazykový kód).

Generátor promptu vychází z principu: TIN je strukturovaná specifikace, ze které se system prompt teprve odvozuje. Jeden TIN → různé prompty pro různé modely.
