Připojení k repozitáři

Web leží ve složce repozitáře na GitHubu. Token zůstává jen v tomto prohlížeči a do repozitáře se nikdy nezapisuje. Stačí jemný token s právem Contents: Read and write pro daný repozitář.

Adresu editoru s repozitářem si můžete uložit do záložek: ?repo=vlastnik/repo&slozka=web&vetev=main
